// what_we_do

什么是"另类"？

我们所说的"另类"，不是标新立异的噱头，而是那些在叙事结构、影像语言、主题表达上偏离主流商业电影范式的作品。它们可能因为题材敏感、节奏缓慢、结构破碎、预算有限而被院线拒绝，但恰恰是这些"不合规"的元素，构成了电影作为一种艺术形式最珍贵的实验场。

独立制作实验影像地下电影先锋艺术
// founding

创立初衷

主流影评只关注票房与奖项，我们希望为那些"不上桌"的影片留一个被讨论的空间。

// audience

目标受众

不满足于类型片套路的观众、影像创作者、电影学研究者，以及对"不一样的电影"有天然好奇的人。

// criteria

收录标准

不以商业成绩为门槛。入选的唯一条件：在影像表达的某一维度上，做到了主流电影不敢做或做不到的事。

// content

内容形式

影片档案 + 深度长评 + 导演访谈 + 幕后解析 + 类型专题策划，多维度呈现每部作品的价值。

SECTION_04

选片方法论

// how_we_select
STEP 01

提名与发现

编辑团队持续关注全球独立电影节（戛纳导演双周、威尼斯地平线、柏林论坛、鹿特丹、釜山新浪潮等），从中筛选具有"另类"潜质的作品。同时接受读者投稿与行业推荐。

STEP 02

三重评估

从叙事创新度（结构是否突破）、影像实验性（视听语言是否有新尝试）、主题勇气（是否触及主流回避的议题）三个维度打分，任一维度达到阈值即可进入候选池。

STEP 03

深度解读

入选影片由至少两名编辑独立撰写解读，涵盖导演意图、技术手法、文化语境三个层面。观点可以冲突，但我们要求论证必须扎实。

STEP 04

归档与更新

完成解读的影片进入另类电影网（lingleidianyingwang-zh.github.io）影像档案库，并持续补充新发现的同类作品，形成类型谱系网络。

常见问题

// faq.md
另类电影网是一个下载站吗？+

不是。另类电影网（lingleidianyingwang-zh.github.io）是一个评论与档案平台，不提供任何影片资源下载。我们提供的是影片信息、深度解读与观看建议，帮助观众找到这些作品的正规观看渠道。

"另类"是否等同于"难看"？+

完全不是。实验性不等于质量低劣。恰恰相反，很多另类电影在艺术完成度上远超商业制作，只是它们的表达方式需要观众调整观看习惯。另类电影网的作用之一就是帮助观众建立这种"解码能力"。

如何向另类电影网推荐影片？+

你可以通过站内联系方式提交影片名称、导演、年代与推荐理由。编辑团队会在每月的选片会上讨论所有读者推荐，入选作品会在片单页面标注推荐人。

内容更新频率如何？+

另类电影网每月更新一次专题策划，每周发布 1-2 篇深度长评，影片档案库持续扩充。重大电影节期间会有特别报道。
